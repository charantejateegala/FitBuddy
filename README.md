# FitBuddy (IRONPULSE Engine) ⚡🏋️️‍♂️

A full-stack fitness tracking and partner discovery platform engineered for high-velocity logging, automated progressive overload targets, and local gym partner matching[span_0](start_span)[span_0](end_span)[span_1](start_span)[span_1](end_span).

---

## ⚡ Core Features

* **High-Velocity Workout Tracker:** Single-tap set logging capturing weight, reps, and RPE with automated ghost targets for progressive overload[span_2](start_span)[span_2](end_span).
* **Live Barbell Sleeve Calculator:** Real-time barbell plate visualizer (25kg, 15kg, 10kg, etc.) to eliminate cognitive load between heavy sets[span_3](start_span)[span_3](end_span).
* **Active Rest Interval Timer:** Built-in countdown timer with instant interval adjustments (+30s, 60s, 90s, 2m, 3m)[span_4](start_span)[span_4](end_span).
* **Partner Discovery Engine:** Filter training partners by discipline (Gym, Running, Cycling, Yoga), skill level, and schedule[span_5](start_span)[span_5](end_span).
* **Direct Messaging:** Peer-to-peer chat for session planning and workout coordination[span_6](start_span)[span_6](end_span).
* **Dynamic Kinetic UI:** Responsive dark-mode interface featuring HTML5 canvas vector animations over glassmorphic containers[span_7](start_span)[span_7](end_span)[span_8](start_span)[span_8](end_span).

## 🛠️ Tech Stack

* **Backend:** Python, Flask, Flask-SQLAlchemy, Flask-Login
* **Database:** SQLite
* **Frontend:** HTML5 Canvas, CSS Glassmorphism, JavaScript
* **Version Control:** Git & GitHub
